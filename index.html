.eml to HTML converter

Pick a saved email file and this pulls out the HTML part, decodes it, and shows the raw markup ready to copy. Everything happens in this browser tab. Nothing is uploaded anywhere.

Decoded HTML

Known limits

  • Inline images stay as cid: references. They will not resolve, which is fine for markup testing.
  • Plain-text-only emails produce a message, not a silent fallback to the text part.
  • Uncommon charsets fall back to UTF-8, and it says so when that happens.
